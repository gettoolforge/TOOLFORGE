JSON Escape / Unescape

Escape text for embedding in JSON — or unescape a JSON string back out.

What gets escaped

  • " → \" · \\ · newline → \n · tab → \t · CR → \r
  • Control characters → \uXXXX
  • Unescape uses the real JSON parser — malformed escapes are reported, not silently mangled.
  • Use case: embedding user text or config values inside a JSON payload safely.
