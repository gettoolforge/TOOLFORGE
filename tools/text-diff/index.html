Text Diff

Compare two texts side by side — additions and removals highlighted.

How it works

  • Classic longest-common-subsequence (LCS) diff at line level — the same core algorithm behind git diff.
  • Green = added, red = removed, dim = unchanged context.
  • Everything computed locally; your documents never leave the tab.
