Why rem

  • rem scales with the user's browser font setting — respecting accessibility. px ignores it.
  • em is relative to the PARENT element's font size (compounds when nested); rem is always relative to the root — predictable.
  • Rule of thumb: font sizes & spacing in rem, fine borders/details in px.
