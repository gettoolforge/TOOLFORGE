Password Strength Checker

Type (or paste) a password — see how long it would survive an attack and what would make it stronger. Analysis happens in your browser only.

    How strength is measured

    • Entropy (bits) = length × log2(alphabet size). Each bit doubles attack time — length is king.
    • Crack times assume an offline attacker with fast hardware (~100 billion guesses/sec) checking common substitutions too.
    • Patterns like password123, qwerty, keyboard walks or years fall to dictionary attacks far faster than raw math suggests — flagged below when detected.
    • This page can't leak your password: there is no server component at all.
    • Best practice: use our Password Generator for new ones and a password manager to remember them.
