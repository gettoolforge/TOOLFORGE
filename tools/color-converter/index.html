Color Converter

Drop in any color format — get HEX, RGB and HSL with a live swatch.

When to use which

  • HEX (#4f8cff): the web default — compact, universally supported.
  • RGB: needed for alpha (rgba) and when mixing light mathematically.
  • HSL: best for humans — hue (color family), saturation (intensity), lightness. Building palettes is trivial: keep H, shift L.
  • Accepted inputs: #abc, #aabbcc, rgb(...), rgba(...), hsl(...) — with or without commas.
