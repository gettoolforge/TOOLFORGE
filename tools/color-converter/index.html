Which format for what?

  • HEX (#4f8cff) — CSS, design tools, brand guidelines.
  • RGB / RGBA — CSS when you need transparency (alpha) control.
  • HSL — the human one: hue in degrees, saturation/lightness in %. Best for creating matching shades by tweaking lightness.
