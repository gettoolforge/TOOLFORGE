XML to JSON

Paste XML — get structured JSON with attributes and text handled sensibly.

Conversion rules

  • Attributes become keys prefixed with @ (@id).
  • Element text lands in #text when attributes coexist; otherwise the element maps to its text directly.
  • Repeated sibling elements become arrays automatically.
  • Empty elements become null. Comments and processing instructions are skipped.
