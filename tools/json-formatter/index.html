Common JSON errors this validator catches

  
    
    
  • Trailing commas: [1, 2, 3,] — invalid in strict JSON, even though JavaScript allows them.
    • 
    
  • Single quotes: keys and strings must use double quotes: {'a': 1} is invalid.
    • 
    
  • Unquoted keys: {a: 1} looks fine in JS but is not valid JSON.
    • 
    
  • Comments: JSON has no comments — // like this breaks parsers.
    • 
    
  • The error message tells you the position of the first problem, so you can fix it fast.
    •
