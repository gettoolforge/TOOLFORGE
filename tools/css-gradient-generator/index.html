CSS notes

  • Gradients are background images — use them on any element via background, no extra markup needed.
  • Angle 90° runs left→right; 180° top→bottom. Radial gradients spread from the center out.
  • Add more stops for multi-color blends; drag the position numbers to compress or stretch transitions.
  • All modern browsers support unprefixed linear-gradient() and radial-gradient().
