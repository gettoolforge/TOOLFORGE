Cheat sheet

  • \d \w \s digit / word char / whitespace · uppercase = negated
  • + * one-or-more / zero-or-more · {2,5} range · ? optional/lazy
  • ( ) capture group · (?: ) non-capturing · $1 in replacement
  • Lookarounds: x(?=y), x(?!y), (?<=y)x, (?<!y)x
  • Flags: g global · i insensitive · m multiline · s dotall
