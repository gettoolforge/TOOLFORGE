Limit notes (2026)

  • X/Twitter counts most URLs as 23 characters regardless of length, and CJK characters as 2 units — this counter shows raw characters.
  • Meta description limit is what Google typically displays (~155–160 chars); longer ones get truncated, not penalized.
  • SMS single segment = 160 chars (or 70 for non-GSM scripts like Finnish ä/ö… actually GSM 03.38 includes them; non-Latin scripts drop to 70).
  • Limits change over time — treat these as the widely-used current values.
