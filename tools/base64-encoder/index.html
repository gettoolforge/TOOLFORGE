Convert text to Base64 and back — full Unicode support (emoji, Finnish ä/ö, CJK all survive the round trip).


What is Base64?

  • A way to represent binary/text data using only 64 safe characters (A–Z a–z 0–9 + /) so it survives email headers, JSON, URLs and old protocols.
  • It is NOT encryption. Anyone can decode it — never use Base64 to hide passwords or secrets.
  • Encoded output is ~33% larger than the input.
  • This tool uses the UTF-8-safe method (TextEncoder), so multi-byte characters don't get mangled — a classic bug in naive converters.
