How the detection works

  • Your browser decodes the audio, then the tool builds an onset energy envelope (where the beats punch) and runs autocorrelation over it to find the repeating pulse.
  • The raw result often reads at half or double speed (a 140 BPM trap beat can read as 70). The table shows the sensible interpretations so you can pick what matches how you count it.
  • Works best on music with a clear steady beat — electronic, hip-hop, pop. Live drumming and rubato classical confuse every detector, including paid ones.
  • Privacy by architecture: the file is decoded with the Web Audio API in your own browser. No server ever receives your music — this is why we can offer it free.
  • Tip for producers: check both this and your DAW's tap-tempo; when they agree you can trust the number.
