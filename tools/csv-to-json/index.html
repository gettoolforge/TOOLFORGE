CSV to JSON Converter

Paste CSV (or drop a .csv file's contents) — get clean JSON with proper types. Quoted fields, commas and newlines inside quotes all handled.



Why another CSV converter?

  • Real parsing, not split-by-comma. Quoted fields like "Smith, John" stay intact; escaped double-quotes ("") work; multi-line quoted cells too.
  • Smart values: 42 becomes a number, true/false booleans, null/"" null — disable with one checkbox if you want strings.
  • Private: your data runs through local JavaScript only — critical when the CSV contains customers or finances. Nothing is uploaded anywhere.
