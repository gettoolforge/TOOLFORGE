UUID Generator

Generate RFC-compliant version-4 UUIDs (GUIDs) using your browser's crypto-grade randomness.



  


  
What is a UUID v4?

  
    
    
  • A 128-bit identifier formatted as xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx — the 4 marks version 4 (random), y is one of 8/9/a/b.
    • 
    
  • Collision odds: you'd need to generate ~2.7 quintillion v4 UUIDs for a 50% chance of one duplicate. In practice: never happens.
    • 
    
  • This generator uses crypto.getRandomValues() — your OS's cryptographically secure RNG, not a weak math function.
    • 
    
  • Everything runs locally: the UUIDs never touch a server, so nobody can precompute or log them.
    • 
  


  
Common questions

  
    
    
  • UUID vs GUID? Same thing — Microsoft calls it GUID, the rest of the world says UUID.
    • 
    
  • Can I use these as database primary keys? Yes, though very large tables sometimes prefer sequential IDs for index performance — UUIDs win when IDs must be unique across systems or generated offline.
