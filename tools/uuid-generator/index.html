UUID Generator

Bulk-generate v4 random UUIDs or v7 time-ordered ones. Cryptographically random.

Which version?

  • v4 — 122 random bits. The default choice; collision odds are astronomically small.
  • v7 — Unix-ms timestamp prefix + random tail. Sorts chronologically, making it ideal for database primary keys (better index locality than v4).
  • Uniqueness: you'd need to generate 2.7 quintillion v4 UUIDs for a 50% chance of one collision.
