How conversion works

  • Input must be a JSON array of objects (or a single object, treated as one row).
  • Nested objects flatten with dot notation: {"user": {"email": "x@y.z"}} → column user.email.
  • Arrays become pipe-joined strings (a | b | c) so nothing is lost.
  • All columns found across every object are included; missing values stay empty.
  • Fields containing the delimiter, quotes or newlines are properly quoted (Excel-safe).
  • Semicolon delimiter is there for European Excel locales that refuse commas.
