YAML → JSON

Paste YAML config — get clean JSON. Indentation, lists and nesting handled.

Supported YAML

  • Nested maps by indentation, flow style {a: 1} and [1, 2]
  • Lists with - dashes (including lists of maps)
  • Quoted strings (single & double), plain scalars, numbers, true/false/null
  • Comments (#) are stripped
  • Not supported: multi-line block scalars (|, >), anchors/aliases — paste those carefully.
