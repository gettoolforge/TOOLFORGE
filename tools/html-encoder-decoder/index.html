HTML Encode / Decode

Escape text for HTML display — or decode entities back to plain text.

When to encode

  • Showing code snippets on a page: <div> must become &lt;div&gt; or the browser renders it.
  • User content inside HTML: prevents broken markup and XSS.
  • The five essential entities: &amp; &lt; &gt; &quot; &#39;. Decode handles 200+ named entities plus &#number; and &xhex;.
