Tips

  • The display updates ~30×/sec but timing uses performance.now() — accurate to sub-millisecond even though you only see milliseconds.
  • "Split" = time of that single lap; "Total" = running elapsed since start.
  • Keep the tab open while running — background tabs throttle timers (the final result stays correct, live view may pause).
