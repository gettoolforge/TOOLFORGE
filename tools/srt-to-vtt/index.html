SRT vs WebVTT — what's the difference?

  
    
    
  • VTT uses dots for milliseconds (00:00:01.000), SRT uses commas (00:00:01,000).
    • 
    
  • VTT starts with a header line: WEBVTT
    • 
    
  • VTT supports cue numbers optionally, plus styling and positioning — HTML5 video players require VTT.
    • 
    
  • SRT is the standard for video editors (Premiere, DaVinci) and most platforms' upload forms.
    •

    Troubleshooting: "no cues could be parsed"
    
    
      
  • Timing lines must look like 00:00:01,000 --> 00:00:03,000 (SRT) or 00:00:01.000 --> 00:00:03.000 (VTT).
    • 
      
  • Cues are separated by blank lines. Make sure your paste didn't collapse them.
    • 
      
  • If timestamps use periods in an SRT file (some editors export that way), this tool still parses them — but check the arrow uses -->.
    • 
    

  


  

    Does this work with non-English subtitles?
    
Yes — output is saved as UTF-8, so Arabic, Chinese, Finnish, and every other script survives intact.

  


  

    Is there a file size limit?
    
No practical one. Subtitles are tiny text files — even feature-film SRTs are under ~100 KB. Your browser does all the work.
