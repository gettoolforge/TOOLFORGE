SQL Formatter

Messy one-line queries in — clean, indented, readable SQL out.

  

Supported statements

  • SELECT: FROM, JOINs (kept with their ON), WHERE, GROUP BY, HAVING, ORDER BY, LIMIT.
  • INSERT INTO … VALUES, UPDATE … SET … WHERE, DELETE FROM … WHERE.
  • Strings in quotes are never touched; keywords inside string literals stay lowercase.
  • This is a pragmatic beautifier for everyday queries, not a full parser for stored procedures.
