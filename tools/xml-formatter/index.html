XML Formatter & Validator

Paste XML — pretty-print it, minify it, or find exactly where it breaks.

What it checks

  • Well-formedness: every tag closed, attributes quoted, single root element.
  • Mismatched tags report the line number of the offender.
  • Self-closing tags (<br/>), comments <!-- -->, CDATA and processing instructions are handled correctly.
  • Formatting preserves text content exactly — whitespace inside elements is untouched, only structural indentation changes.
  • Great for sitemaps, RSS feeds, Android layouts, SOAP responses and config files.
