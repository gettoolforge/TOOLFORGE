Hash Generator

SHA-256 / SHA-384 / SHA-512 fingerprints of any text — computed locally with your browser's native crypto engine.

Which hash for what?

  • SHA-256 — today's default for file integrity, signatures, blockchains.
  • SHA-512 — same family, longer digest; fine anywhere a long fingerprint helps.
  • SHA-1 — legacy only; broken for security purposes since 2017 (kept here because some old systems still ask for it).
  • A hash is one-way: you can't recover the text from it. Identical text always yields an identical hash — that's how integrity checks work.
