How it works

  • BPM: onset-energy envelope + autocorrelation with harmonic candidate voting. Half-time / double-time interpretations are shown because a 140 BPM trap beat legitimately reads as 70 at the half-note level.
  • Key: FFT chromagram correlated against Krumhansl-Kessler psychoacoustic key profiles across all 24 major/minor keys, with runner-up candidates listed.
  • Accuracy notes: works best on steady-beat music (electronic, hip-hop, pop) with harmonic content (chords, melody). Drum-only loops weaken key detection; live drumming weakens BPM. For produced beats, results are usually solid.
  • Privacy by architecture: decoding happens with the Web Audio API in your browser — no server ever receives your file. That's why this can be free.
